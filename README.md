# Projet-Python-M1
Projet dans le cadre de l'UE "Programmation objet en Python" du Master "Systèmes Intelligents" de Sorbonne Université. Le but est de coder un jeu vidéo de course inspiré de jeux tels que Mario Kart et Trackmania.

## Prérequis

- Python 3
- pip

## Installation

1. Cloner le dépôt
    ```sh
    git clone https://github.com/Loan-std/Projet-Python-M1.git
    ```

2. Créer un environnement virtuel

3. Installer les dépendances
    ```sh
    pip install -r requirements.txt
    ```


## Utilisation

```sh
python main.py
```
